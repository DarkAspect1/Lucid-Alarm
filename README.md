## Overview

Lucid Alarm is an open-source Android application built with Jetpack Compose. Designed to extend the Samsung One UI aesthetic, it combines borderless containers and a comprehensive visual customization engine in a single suite covering **Alarms**, **World Clock**, **Stopwatch**, and **Timer**.

Every surface, dial, and card adapts to the user's chosen accent color and global typography.

---

## Features

### Design System and UI Architecture

| Feature | Description |
| :--- | :--- |
| **Borderless Design Language** | Cards, menus, floating buttons, and pills use no outlines, reducing visual clutter across the interface. |
| **Edge Fade Masks** | Offscreen `BlendMode.DstIn` vertical alpha masks let scrollable content fade naturally at the top and bottom of the viewport. |
| **Floating Capsule Navigation** | A compact, borderless navigation capsule sits above the system navigation bar with active tab indicators. |
| **Contextual Floating Actions** | Matched 48dp circular buttons for Add and Menu/Settings, positioned consistently across all tabs. |
| **Scroll-Aware Back to Top** | A circular button driven by `derivedStateOf` animates into view on long lists and returns the user to the top. |

### Selection and Organization

* **Multi-select batch actions:** Long-press any alarm or world clock card to enter selection mode, with the following actions available:
  * Select all / deselect all
  * Move to group
  * Duplicate
  * Toggle on or off
  * Move to recycle bin
* **Two-column alarm groups:** Groups render in a two-column grid (`groups.chunked(2)`) with live alarm counts, outline status icons (`Alarm` / `AlarmOff`), and bulk group switches.
* **Filtering and sorting:**
  * Status filter: All, Turned On, or Turned Off
  * Day filter: Restrict alarms to specific days of the week
  * Sort order: Alarm Time, Alarm Day, or drag-and-drop Custom Order
* **Recycle bin:** A two-stage deletion workflow supporting individual restore, bulk restore, and permanent deletion.

## Alarm Customization

The flagship capability of Lucid Clock is its alarm personalization engine, configurable globally or per alarm.

### Clock Layouts and Canvas Scaling

* **Six selectable layouts:**
  * Horizontal (`08 : 00 AM`)
  * Vertical Stacked (`08` over `00`)
  * Bold Horizontal
  * Bold Vertical
  * Compact Analog
  * Numbered Analog
* **Aspect-locked resize handle:** A corner handle on the preview canvas scales the clock digits freely while preserving proportions.

### Interactive Background Engine

* **Built-in ambient styles:**
  * Dark Midnight Gradient and Pure AMOLED Black
  * Warm Sunrise and Dynamic Fluid Gradient
  * Starfield Particle Drift (physics-based particle layers)
  * Interactive Mesh Gradient and Interactive Aurora Borealis
  * Interactive Fireflies and Solid Color Palette
* **Custom media:**
  * Custom image wallpaper loader
  * Looping, muted custom video wallpaper (`.mp4`, `.mkv`) with hardware decoding
* **Dimming control:** Adjustable darkening scrim (0% to 100%) over the background.

### Typography and Element Control

* **Color selection:** A 24-preset curated grid, or a full HSV spectrum with hex input (`#RRGGBB`).
* **Color and gradient options for:**
  * Clock digits
  * Date display
  * Dismiss button (container and label)
  * Snooze button (container and label)
* **Custom font support:** Load any `.ttf`, `.otf`, or `.apk` font file from device storage.
* **Display controls:** Independent visibility toggles for the date, AM/PM indicator, and alarm label.

## Nowbar and Live Activities

Lucid Clock integrates with background and lock screen Live Activities, referred to as the Nowbar.

* **Floating heads-up pill:** Real-time countdown and stopwatch counters rendered on the system UI and lock screen.
* **In-place controls without launching the app:**
  * Stopwatch: Lap and Stop
  * Timer: Pause, Resume, and Cancel
* **Multi-instance stacking:** The stopwatch and timer can run simultaneously in stacked floating capsules.
* **Adapts to accent color**

## Wake and Notification Policies

* **Post-dismissal wake check:** A configurable delay (1 to 15 minutes) triggers a secondary confirmation prompt to help prevent accidentally oversleeping.
* **Upcoming alarm alerts:** Dismiss or modify an upcoming alarm directly from its notification, with configurable lead times from 15 to 60 minutes.
* **Audio and haptics:** Unified or per-alarm volume override, custom ringtone selection, and distinct vibration patterns (Tick-Tick, Continuous Buzz, Urgent Staccato).

## Architecture and Tech Stack

```
Lucid-Alarm/
├── app/
│   ├── src/main/java/com/lucid/clock/
│   │   ├── data/                 # Room database, DAOs, and entities
│   │   ├── datastore/            # User preferences DataStore and backups
│   │   ├── notifications/        # AlarmManager, WorkManager, and Nowbar service
│   │   ├── ui/
│   │   │   ├── alarms/           # Alarm list and group management
│   │   │   ├── customization/    # Clock and ringing appearance canvas
│   │   │   ├── worldclock/       # World clock list and timezone engine
│   │   │   ├── stopwatch/        # Dial canvas and lap table
│   │   │   ├── timer/            # Wheel pickers and progress rings
│   │   │   ├── settings/         # Grouped settings and color engine
│   │   │   ├── components/       # Shared components and floating nav capsule
│   │   │   └── theme/            # Color schemes, brushes, and typography
│   │   └── ClockApplication.kt
│   └── build.gradle.kts
```

| Area | Implementation |
| :--- | :--- |
| **UI framework** | 100% Jetpack Compose |
| **State management** | Kotlin Coroutines, StateFlow, and Jetpack ViewModel |
| **Persistence** | Room (alarms, recycle bin, groups) and Jetpack DataStore (preferences) |
| **Minification** | R8 and ProGuard rules protecting Room entities and JSON serialization models |

## Building and Release

### Prerequisites

* Android Studio Ladybug or Meerkat, or newer
* JDK 17 or newer
* Android SDK 34 or newer

### Clone and Build

```bash
# Clone the repository
git clone https://github.com/DarkAspect1/Lucid-Alarm.git
cd Lucid-Alarm

# Build a debug APK
./gradlew assembleDebug

# Build an optimized, R8-minified release APK
./gradlew assembleRelease
```

The release binary is written to `app/build/outputs/apk/release/app-release.apk`.
